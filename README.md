# Thiranex Internship - Task 3
## JavaScript Logic & State Management — To-Do List

### Features
- Create tasks
- Read/display tasks
- Update/edit tasks
- Mark tasks complete/incomplete
- Delete tasks
- All / Active / Completed filtering
- Clear completed
- Clear all
- Automatic localStorage persistence
- Data survives browser refresh
- Dynamic DOM rendering
- Event delegation for task actions
- Accessible labels and keyboard interactions
- Responsive mobile layout

### Files
- index.html
- style.css
- script.js

### Run
Open `index.html` in a browser or use VS Code Live Server.

### localStorage
Tasks are stored under:
`thiranex_tasks_v1`

The app reads saved state on startup and writes the updated state after every CRUD operation.
